35 GHz 分路，两条倍频路径

中央 DA 驱动 1:8 功率分配网络，四路送 TX，四路送 RX 本振。TX 经 VGA、VMPS、×4 和 PA 到 140 GHz；RX 的 35 GHz 支路先 ×2 到 70 GHz，再用次谐波混频器对 140 GHz 回波去斜。

公式与使用边界

ℒRF = 10 log₁₀(M²·10^(ℒPLL/10) + 10^(ℒadd/10))
理想倍频使输入相噪贡献恶化 20 log₁₀M；此处不模拟 PLL 环路传递。

Sφ,IF = 4 sin²(π foffset τ) · 16Sφ,35G + Sφ,branch + Sφ,IFadd
foffset 是目标谱线旁的偏移频率。35 GHz 公共源相位在 TX ×4、RX ×2 加二次谐波混频后均等效乘以 4。只有公共源贡献乘相关因子；各支路独立附加噪声直接相加。

SNRj = −20 log₁₀(2π |fbeat| σt)
σt 为采样时钟与孔径抖动的均方根合成值。这里代入 IF 拍频，不是 RF 载频。

SNRq ≈ 6.02·ENOB + 1.76 dB
满量程正弦等效量化上限；小信号会损失相应的满量程回退量。未包含杂散和非线性。

MODEL & REFERENCES

与参考图一致的 4TX–4RX 连接

四行通道从上到下对应 1–4。左侧每行按 RX 天线 → LNA → SHM → IF 排列，×2 倍频器位于接收链旁；右侧每行按 VGA → VMPS → ×4 → PA → TX 天线排列。中间是 DA 与 35 GHz 的 1:8 分配树，FMCW 合成器在底部，SPI / LDO 在顶部。

三维外形采用便于观察的功能展开，不按 LTCC 层叠或芯片制造尺寸复刻。外部参考、采样时钟、ADC 与 DSP 放在独立采集区；这些系统补全部分不冒充参考芯片上的集成模块。

可尝试的三个实验

预算口径

  • 所有工作点都是可调教学假设。载频与带宽可调不意味着同一实体电路覆盖所有频段；实际选型还需检查器件带宽、增益、匹配与线性度。
  • EIRP 表示朝目标方向的等效发射功率；EINF = NF − G_RX（dB）把接收噪声折算到各向同性天线口径。预算不再重复加入 TX / RX 天线增益。
  • 差分实数 IF 的 LPF 截止作为等效矩形噪声带宽 Bn 的教学近似。处理前噪声与处理增益使用同一带宽；最终相干 SNR 由能量式计算，不能重复加 FFT 样点增益。
  • 单目标、线性上扫频、恒速。定义 fbeat = Sτ − fD，正速度表示接近。参考图的差分 IF 不是 I/Q；实数谱观察 |fbeat|。每路 ADC 使用采样率 fs，限制 |fbeat| < min(BIF, fs/2)。R–D 图仅用于解释理想慢时间尺度，不声称解决实数 IF 的符号歧义。
  • 检测结果只计热噪声及输入的实现损耗。杂波、多径、泄漏、相噪、量化、压缩与 ADC 饱和没有合成进检测 SNR；量化和抖动上限单独展示。检测门限是设计输入，不是完整 CFAR 性能。

Pr,iso = EIRP·λ²σ / ((4π)³R⁴L)
线性单位；接收参考面为等效各向同性天线。

SNR = Pr,iso·N·Tobs / (kT₀·Fiso·Limp)
Fiso = 10^(EINF/10)，Tobs = Tc − 2R/c。

ΔR = c/(2B)；fb = Sτ − 2v/λ
有限观测修正为 c/(2S·Tobs)。

|v|max = λ/(4Trep)
理想等周期相干 chirp 序列的速度边界。

参考结构与教学预算的区别

Liu 等 ISSCC 2025 的 132–148 GHz 4TX–4RX 雷达提供了系统设计参考：峰值 EIRP 28.7 dBm、最小 EINF 7.8 dB，以及角反射器测得的 1.3 cm 分辨率和约 16.8 m 测距。本页采用参考图中的 1:8 分配、TX 四倍频和 RX 70 GHz 次谐波混频架构，几何外形与预算输入做教学简化。4TX / 4RX 不自动代表 16 个虚拟 MIMO 通道，预算不额外加入四路接收合并增益。

论文 24 GHz 的合成器扫频能力与 132–148 GHz TX 3 dB 带宽属于不同测试；当前参数也不用于复现这些实测结果。
